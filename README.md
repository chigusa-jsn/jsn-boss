# JSN Boss

Minecraft 1.21.1 / NeoForge 向けのオリジナルボス MOD。モデルとアニメーションは GeckoLib。

## ボス

### 炎の騎士（`jsnboss:fire_knight`）

身長3.5ブロック、HP 1500。燃える大剣を持った黒鉄の騎士。HP が半分（750）を切ると第2形態になり、炎が青く変わる。

| 技 | 第1形態 | 第2形態 | 使う距離 |
|---|---|---|---|
| 横なぎ | 12 | 16 | 近い |
| 3連撃 | — | 12・12・18 | 近い |
| 突進斬り | 15 | 20 | 中くらい |
| 跳躍叩きつけ | — | 22 | 中〜遠い |
| 火柱 | 10＋炎上（1本） | **必ず15**（3本） | どこでも |
| 火の玉 | 9＋炎上（1発） | 12＋蒼炎（3発、燃える地面が残る） | 遠い |
| 飛ぶ斬撃 | 10（横：ジャンプで避ける） | 14（縦→横の2連発） | 中〜遠い |

- 数字は難易度ノーマルの値。変えるときは `FireKnightEntity.java` の `dmg(第1形態, 第2形態)` を書き換える
- 青い火柱は防具・エンチャント・効果・盾・難易度を無視する（`data/minecraft/tags/damage_type/`）。不死のトーテムは効く
- 蒼炎：1秒ごとに1ダメージ。水に入っても消えない

## ボスバー

ボスごとに専用デザインのボスバーが出る（キングダムハーツ方式）。

- 形態ごとにバーが1本。バーがなくなると次の形態になり、空から満タンまで溜まり直す（そのときバーが白く光る）
- 左下の小さな印が「控えのバーの本数」。形はボスごとに違う（炎の騎士は燃えさし、氷の魔女は氷の欠片、ゾンビの王はどくろ、ユグドラシルは種 など）
- 受けたダメージはクリーム色の帯で少し残り、遅れて減っていく
- ゾンビの王（復活あり）とユグドラシル（第3形態あり）はバーが3本
- 紋章・枠の飾り・色は形態ごとに変わる（例：炎の騎士は赤い炎→青い炎、ユグドラシルは緑→紅葉→金色の花）

## ボスBGM

オリジナルのボス曲が流れる。対象のボスが近く（80ブロック以内）にいる間だけループで流れ、倒すか離れると3秒でフェードアウトする。流れている間はバニラのBGMは止まる。音量は設定の「音楽」スライダーで変えられる（ボス曲はゲーム内で大きすぎないよう、さらに6割に抑えてある）。全部ボスごとの専用曲で、パルス波（ピコピコ音）でそろえている。近くにボスが何体かいるときは、ユグドラシル系が優先、それ以外は一番近いボスの曲。形態が変わると、1秒で前の曲が消えて次の曲に切り替わる。

バニラのモブのモデルそのままで、色と技がちがう。自然に湧くとき、一定の確率でバニラのモブと入れ替わる（スポーンエッグもある）。**亜種の HP はどれも 50**（光るスライムは大きさ4のとき50）。

| 亜種 | 元のモブ | 出やすさ | 特徴 |
|---|---|---|---|
| 蒼炎のブレイズ（`soul_blaze`） | ブレイズ | 10% | 青い炎の弾を3連射。当たると蒼炎（水でも消えない） |
| 氷結のブレイズ（`frost_blaze`） | ブレイズ | 10% | 氷の弾を3連射。当たると凍えて鈍くなる。水が平気 |
| 王墓のゾンビ（`tomb_zombie`） | ハスク | 20% | 包帯のミイラ。殴られると空腹＋一瞬の盲目（呪いの砂） |
| 雷のゾンビ（`thunder_zombie`） | ゾンビ | 4%（雷雨のときは30%） | 殴られると感電して1秒スタン。雷に打たれると回復 |
| 炎の弓兵（`fire_skeleton`） | スケルトン | 5% | 火のついた矢を3本同時に撃つ。火が効かない |
| 毒の弓兵（`poison_skeleton`） | スケルトン | 5% | 当たった場所に毒の霧が広がる矢 |

| 森の苔ゾンビ（`moss_zombie`） | ゾンビ | 森・ジャングル・タイガで15%（ほかは4%） | 苔とツタに覆われている。攻撃で鈍足 |
| べたべたグモ（`honey_spider`） | クモ | 6% | ハチミツとスライムまみれ。噛まれるとくっつく（鈍足＋3秒ジャンプできない） |

| 光るスライム（`glow_slime`） | スライム | 15% | 黄緑に光る。攻撃で発光 |

### テーマ亜種（全部のモブ）

上の「森の苔ゾンビ」〜「光るスライム」の8つのテーマは、**ゾンビ・スケルトン・クモ・スライム・ブレイズ・クリーパーの全部**にある（8テーマ × 6種類 = 48種類。名前は `テーマ_モブ`、例：`sky_zombie`、`gold_blaze`、`ore_creeper`。海のゾンビだけはドラウンド）。

- 効果とドロップはテーマで決まる（ブレイズは火の玉、クリーパーは爆発、スケルトンは矢に効果が乗る）。テーマのクリーパーの爆発はブロックを壊さない
- 鉱石のテーマは、どのモブでも深さで 石・鉄・金・ダイヤ の4段階
- 光るテーマは体が暗いところでも明るく見える
- スライムは分裂するので、大きさ2以上だけがドロップを落とす（レアは大きさ4だけ）

| テーマ | 出る場所 | 効果 |
|---|---|---|
| 森の | 森・ジャングル・タイガ・沼 | 鈍足 |
| べたべた | 花の森・草原・ヒマワリ平原・桜の林 | くっつく（鈍足＋ジャンプできない） |
| 海の | 海・砂浜・川 | 採掘速度低下 |
| 空の | 高さ100より上・山 | 打ち上げ |
| 黄金の | 荒野・ネザー | 弱体化＋毒（ライトマンのコインも落とす） |
| 残響の | 高さ0より下 | 暗闇（倒すと10%でウォーデン） |
| 鉱石の | 高さ40より下・ネザー | 深いほど硬い |
| 光る | 繁茂した洞窟・沼・マングローブ・キノコ島 | 発光（本人もいつも発光していて、壁越しでも見える） |

- その場所に合うテーマがあると、ゾンビ・スケルトン・クモ・スライム・ブレイズ・クリーパーが湧いたとき 20% でテーマ亜種になる（ネザーのブレイズは黄金か鉱石）
- ふだんは出ない場所でも、テーマの場所ではまれに（1.5%）テーマのブレイズやスライムが出る

新しい8体のドロップ：

| 亜種 | ドロップ |

| 黄金のゾンビ | 金塊・金インゴット・金のニンジン・きらめくスイカ・金のリンゴ・金ブロック（下ほどレア）＋銅コイン（少量）・鉄コイン（中量）・金コイン（大量） |

## エリートモブ

自然に湧いた敵モブ（バニラと亜種）が 6% の確率で特性つきの強い個体になる。名前の頭に特性がつき（見たときに表示）、周りに特性の色のオーラが出る。**HP 100**（巨大な・肉の は 150）、攻撃力 1.3倍、経験値3倍。幸運の・復活の・絶望の は出にくい。

| 特性 | 効果 | ドロップ |
|---|---|---|
| 炎の | 攻撃で5秒炎上。火が効かない | 火打石・ブレイズパウダー。ときどきブレイズロッド、まれにドラゴンブレス |
| 氷の | 攻撃で凍える＋鈍化 | エメラルド1〜3（ときどきダイヤ・金のリンゴ） |
| 雷の | 攻撃で1秒スタン | 〃 |
| 巨大な | 体が1.5倍、HP 150、攻撃力1.5倍、ノックバックしにくい | 〃 |
| 吸血の | 与えたダメージの半分だけ回復 | 〃 |
| 再生の | 毎秒2回復（殴られてから3秒は回復しない） | ガストの涙。まれにエンチャントされた金のリンゴ |
| 分裂の | 倒すと HP 25 の小さな2体に分かれる | エメラルド1〜3（ときどきダイヤ・金のリンゴ） |
| 群れを呼ぶ | 12秒ごとに同じモブ（ふつうの HP）を呼ぶ（近くに3体まで） | 〃 |
| 毒の | 攻撃で毒II | 青くなったジャガイモ・フグ・クモの目。ときどき毒のポーション |
| 肉の | HP 150 | 生肉（牛・豚・鶏・羊・ウサギ）3つ |
| 幸運の | 攻撃でランダムな効果（いい効果も悪い効果も） | ウサギの足・皮。ときどき幸運のポーション・ダイヤ、まれにドラゴンブレス・残響の欠片・エンチャントされた金のリンゴ・海洋の心、ごくまれにネザースター |
| 爆発の | 倒すと爆発（ブロックは壊さない） | 火薬・ファイヤーチャージ・花火・石炭 |

- 矢などの飛び道具でも、撃った本人がエリートなら特性の効果がつく
- 試すときは `/jsnboss elite <モブ> <特性>`（例：`/jsnboss elite minecraft:zombie fire`）。特性は fire, ice, thunder, giant, vampiric, regen, split, summon, poison, meat, lucky, explosive, revive, despair
- 確率を変えるときは `mob/EliteMobs.java` の `CHANCE`、亜種の出やすさは `mob/MobEvents.java` の `pickVariant`

## クリエイティブタブ

スポーンエッグは「JSN Boss ボス」と「JSN Boss 亜種モブ」の2つのタブに分かれている。

## 最大HPの上限について

バニラの最大HPは1024が上限なので、この MOD は起動時に上限を100000まで引き上げている（`BossSetup.raiseMaxHealthCap()`、`META-INF/accesstransformer.cfg`）。ほかのモブのHPは変わらない。

## 遊び方

```
./gradlew runClient
```

- クリエイティブの「JSN Boss ボス」「JSN Boss 亜種モブ」タブにスポーンエッグ
- コマンド：`/summon jsnboss:fire_knight`、`/summon jsnboss:ice_witch`、`/summon jsnboss:zombie_king`、`/summon jsnboss:dark_mage`、`/summon jsnboss:blade_dragon`、`/summon jsnboss:white_fox`、`/summon jsnboss:wind_cat`、`/summon jsnboss:thunder_lion`、`/summon jsnboss:rock_giant`、`/summon jsnboss:ender_sentinel`、`/summon jsnboss:creeper_mother`、`/summon jsnboss:fenrir`、`/summon jsnboss:iron_spider`、`/summon jsnboss:fallen_valkyrie`、`/summon jsnboss:yggdrasil`、`/summon jsnboss:yggdrasil_spirit`
- 第2形態をすぐ見たいとき：`/data merge entity @e[type=jsnboss:fire_knight,limit=1] {Health:740f}`（ice_witch も同じ、zombie_king は 990f、dark_mage は 590f、blade_dragon は 990f、white_fox と wind_cat は 790f、thunder_lion は 890f、rock_giant は 1090f、ender_sentinel と creeper_mother は 790f、fenrir と iron_spider は 990f、fallen_valkyrie は 1090f、yggdrasil は 1490f。ユグドラシルの第3形態は第2形態で `/damage @e[type=jsnboss:yggdrasil,limit=1] 2000` のように倒すと見られる。精霊の第5形態は 1490f）

配布用の jar は `./gradlew build` で `build/libs/` にできる。GitHub に push すると Actions が自動でビルドする（jar は Actions の実行結果からダウンロードできる）。
